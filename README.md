# ashiya 的小站 (ashiyachion.me)

个人小站源码。纯静态 HTML / CSS / JS，无需构建，托管于 GitHub Pages。

## 目录结构

```text
ashiyachion-me/
├── index.html          # 页面结构
├── 404.html            # GitHub Pages 自动使用的 404 页面
├── CNAME               # 自定义域名 ashiyachion.me（不要删除）
├── .nojekyll           # 跳过 Jekyll 处理
└── assets/
    ├── favicon.svg
    ├── css/style.css   # 样式（浅色 / 深色主题变量在文件开头）
    └── js/
        ├── data.js     # 全部内容都在这里
        └── app.js      # 交互逻辑
```
