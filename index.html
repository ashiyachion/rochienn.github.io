自動化 × 資料 已完成

表格流水線 Python 重構

把一套用 Power Query（M 語言）寫的多表處理流程，改寫成 pandas + openpyxl 的模組化 Python 專案，支援依資料夾批次讀取、關鍵字去重與類目對應。

  1. config.yaml + Excel 資料夾
  2. 類目對應關鍵字清洗流水合併
  3. DataFrame / Excel
做了什麼
  • 用 config.yaml 管理路徑，不再寫死在程式裡。
  • 每一步都是回傳 DataFrame 的函式，方便單獨測試。
  • 用 pytest 覆蓋空值、重複鍵等邊界情況。
